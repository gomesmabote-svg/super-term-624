# Hotflix Junica

Versão Hotflix Junica do site, pronta para publicação.

## Estrutura
- index.html — página principal
- app_v=p5.js — lógica da aplicação
- brand_v=2.js — branding/footer
- store-catalog.js — catálogo
- store-templates_v=p4.js — templates
- open-external_v=8.js — links externos
- style_v=p2.css — estilos principais
- store-templates_v=p4.css — estilos de templates
- brand.css — estilos de marca
- mock-store.json — dados locais do catálogo (com CTA configurado)
- brand/ — logos e favicon

## Como testar localmente

1. Abra a pasta do projeto em um servidor local.
2. Acesse a página principal em http://localhost:8000/
3. Ou use um servidor simples com:
   python -m http.server 8000
4. Teste a URL do catálogo com:
   http://localhost:8000/?store=hotseller
